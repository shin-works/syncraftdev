Integritetspolicy

Ikraftträdandedatum: 28 augusti 2026
Senast uppdaterad: 18 oktober 2026

Denna integritetspolicy förklarar hur SynCraft ("vi", "oss" eller "vår") hanterar användarinformation i iOS-applikationen SwingCat ("Appen").

1. Information som vi samlar in och lagrar

Appen kräver generellt sett inte att användare direkt anger namn, adress, telefonnummer eller e-postadress för att registrera sig.

Beroende på hur appen används kan följande information lagras på din enhet: timerinställningar; fokustid och timerhistorik; uppgifter som du har angett; katter, föremål, titlar och annat innehåll i appen och deras användning; appinställningar; valfri profilinformation såsom ett namn; och status för betalda funktioner.

Vi kan också komma att samla in eller behandla information via tredjepartstjänster för användningsanalys, kvalitetsförbättringar, diagnostik och annonsering. Detta kan inkludera enhetstyp, operativsystem, språkinställningar, appversion, start- och funktionsanvändningshändelser, krasch- och prestandadata, IP-adress och annan nätverksinformation, annonsinteraktioner och enhets- eller annonsidentifierare. Den information som faktiskt behandlas kan variera beroende på din iOS-version, enhetsinställningar, sekretessval, samtyckesstatus och specifikationer för tredjepartstjänster.

2. Hur vi använder information

  1. För att tillhandahålla appen och dess funktioner.
  2. För att förstå och analysera appanvändning.
  3. För att förbättra funktioner, användbarhet och användarupplevelse.
  4. För att undersöka och åtgärda fel, krascher och andra problem.
  5. För att visa reklam och tillhandahålla reklamrelaterade funktioner.
  6. För att tillhandahålla belöningar i appen i samband med annonsering.
  7. För att förhindra missbruk.
  8. För att tillhandahålla betalda funktioner och bekräfta köpstatus.
  9. För att svara på förfrågningar.

3. Firebase

Vi kan komma att använda tjänster som tillhandahålls av Google LLC, inklusive Firebase Analytics för att förstå appanvändning och förbättra funktioner, och Firebase Crashlytics för att identifiera krascher och förbättra stabiliteten. Dessa tjänster kan samla in eller bearbeta användningsinformation, enhets- och operativsysteminformation, kraschloggar, appens status och annan diagnostisk information.

Googles integritetspolicy och andra tillämpliga villkor gäller för information som hanteras av Firebase. Googles integritetspolicy
Firebase integritet och säkerhet

4. Google AdMob

Vi kan komma att använda Google AdMob för att visa annonser. Appen kan erbjuda belöningsannonser genom vilka användare kan få varor eller andra förmåner i appen. AdMob och Google Mobile Ads SDK kan samla in eller behandla IP-adresser, enhetsinformation, enhets- eller annonsidentifierare, annonsvisningar och interaktioner, interaktioner i appen och krasch- eller prestandainformation för annonsvisning, mätning, bedrägeriförebyggande åtgärder och tjänsteförbättring.

Tillgängligheten av annonsidentifierare kan bero på enhetsinställningar, Apples sekretessfunktioner och användarnas samtycke. Googles sekretesspolicy
Hur Google använder data från partnerwebbplatser eller appar

5. Köp i appen

Vi kan komma att erbjuda prenumerationer och engångsköp via App Store. Apple behandlar betalningar och vi samlar inte in eller lagrar direkt kreditkortsnummer eller andra betalningsuppgifter. För att tillhandahålla betalda funktioner kan appen komma åt eller verifiera information om köpta produkter och prenumerationsstatus. Apples integritetspolicy

Vi använder RevenueCat, Inc. för att verifiera köp, hantera åtkomst till prenumerationer och betalda funktioner, återställa köp och förstå köp- och prenumerationsaktivitet. RevenueCat behandlar ett appanvändar-ID som genereras av dess SDK, köpta produktidentifierare, information om transaktioner och köphistorik, prenumerationsstatus och utgångsdatum samt teknisk information såsom enhetens operativsystem och appversion.

Vi använder RevenueCats automatiskt genererade anonyma appanvändar-ID istället för att ange ett namn eller en e-postadress som din köpidentifierare. Vi skickar inte ditt profilnamn eller din e-postadress i appen till RevenueCat som kundattribut. Användningen av ett anonymt ID innebär inte att ingen information behandlas eller att köpregister raderas när du avinstallerar appen.

För mer information, se RevenueCats integritetspolicy och RevenueCats information om köpdata.

6. Delning med tredje part

Vi säljer inte information om användare. Information kan skickas till eller behandlas av Firebase, Google AdMob, Apple, RevenueCat och andra tjänster efter behov för att tillhandahålla appen. Vi kan också lämna ut information där du samtycker, där utlämnande krävs enligt lag, där det är nödvändigt för att skydda liv, kropp eller egendom, eller enligt vad som annars är tillåtet enligt lag.

7. Datalagring och radering

Timerhistorik, katter, objekt, titlar, inställningar och annan appdata kan lagras på din enhet. Data som endast lagras på en enhet kan gå förlorade om appen raderas, enheten återställs, enheten slutar fungera eller av andra skäl. Data som behandlas av tredjepartstjänster hanteras enligt deras respektive lagringsperioder och policyer.

Att avinstallera appen raderar inte i sig köpregister eller annan information som innehas av tredjepartstjänster. För frågor eller förfrågningar om åtkomst till eller radering av din information, kontakta oss på hello@syncraft.dev. Vi kommer att hantera förfrågningar i enlighet med tillämplig lag; vissa register kan behöva behållas för att uppfylla rättsliga skyldigheter eller verifiera köp.

8. Reklam och sekretessval

Hur annonser visas kan variera beroende på region, enhetsinställningar, Apples sekretessfunktioner, samtyckesstatus och andra villkor. Vid behov kan vi visa en skärm som ber om samtycke eller ett val gällande annonser eller annan dataanvändning. Du kan hantera användningen av annonsidentifierare och annan information i den utsträckning det är möjligt via iOS sekretessinställningar.

9. Barn

Minderåriga bör använda appen med samtycke från en förälder eller vårdnadshavare vid behov. Appen är inte utformad för att aktivt samla in personlig information såsom ett barns namn, adress, telefonnummer eller e-postadress.

10. Säkerhet

Vi strävar efter att vidta rimliga säkerhetsåtgärder för att förhindra obehörig åtkomst, läckage, ändring, förlust och liknande händelser som rör information som hanteras via appen.

11. Ändringar i denna policy

Vi kan komma att ändra denna policy vid behov på grund av juridiska ändringar, ändringar i appens funktioner, ändringar i tredjepartstjänster eller andra skäl. Den reviderade policyn träder i kraft när den publiceras i appen eller på vår webbplats. Vi kommer att meddela om väsentliga ändringar där så är lämpligt.
